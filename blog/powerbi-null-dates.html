Handling Null Values in Power Query Date Conversions

Why text to date conversions return nulls, and the step by step fixes that work

By Teslim Adeyanju · 15 November 2026 · 3 min read

Text to date conversions in Power Query return null when the format does not match your locale, the data contains invalid values, or the column has no consistent pattern. This post shows how to find the cause and fix it with Change Type using Locale, data cleaning and M code.

Understanding Why Nulls Appear

When Power Query converts text to dates and returns null values, it is typically due to one of these reasons.

Unrecognised Date Format

Power Query can only convert text to Date when the format matches your system's locale settings. If your system expects MM/DD/YYYY but the data is in DD/MM/YYYY format (or the other way round), the conversion fails and returns null.

Invalid or Mixed Values

Your data may contain entries that cannot be interpreted as dates:

  • Placeholder text like "N/A"
  • Invalid dates like "2025-13-01" (month 13 does not exist)
  • Empty cells or inconsistent formatting

Column From Examples Limitation

When Power Query cannot identify a consistent transformation pattern across your data, the "Column From Examples" feature produces nulls. This happens when your source column has inconsistent or invalid formats.

Step by Step Solutions

Step 1: Inspect Your Source Data

Before attempting any conversion, examine your "Order Date" column:

  • What format are the dates in? Examples: 2025-11-30, 30/11/2025, 11/30/2025
  • Do any values include time? Example: 2025-11-30 14:35:00
  • Are there any non-date values mixed in?

Step 2: Use Change Type with Locale

This is the most reliable method for converting dates in a specific format:

  1. Right-click the column header
  2. Select Change Type, then Using Locale
  3. In the dialog, set Data Type to Date and choose the Locale that matches your source:
    • English (United States) for MM/DD/YYYY
    • English (United Kingdom) for DD/MM/YYYY
  4. Click OK

This tells Power Query exactly how to interpret the text values.

Step 3: Clean Your Data First

Before conversion, remove or fix problematic values.

Remove invalid text:

  • Select the column
  • Go to Transform, then Replace Values
  • Replace "N/A" or other placeholders with null, or remove them

Remove extra spaces:

  • Select the column
  • Go to Transform, then Format, then Trim

Step 4: Handle Date and Time Values

If your column contains both date and time (for example 2025-11-30 14:35:00):

  1. First, change the type to Date/Time
  2. Then extract just the date: right-click the column, choose Transform, then Date, then Date Only

Step 5: Advanced M Code Solution

For more control, use M code to parse dates explicitly:

// Convert the Order Date column using an explicit locale
        = Table.TransformColumns(
            Source,
            {{"Order Date", each Date.FromText(_, "en-GB"), type date}}
        )

Notes:

  • Replace "en-GB" with the appropriate locale code
  • "en-GB" handles DD/MM/YYYY format
  • "en-US" handles MM/DD/YYYY format

Best Practices

  • Always use Change Type with Locale for dates in non-standard formats
  • Clean invalid or placeholder values before attempting conversion
  • If Column From Examples produces nulls, your source format is likely inconsistent

Troubleshooting Checklist

  1. Check sample values to identify the date format
  2. Look for non-date values that need cleaning
  3. Verify your system locale matches your approach
  4. Use locale specific conversion when needed
  5. Handle date and time columns by extracting the date after the initial conversion

Quick Reference

When you see nulls in date columns:

  1. Inspect: what does the source text look like?
  2. Clean: remove invalid values and trim spaces
  3. Convert: use "Change Type with Locale"
  4. Verify: check whether any nulls remain and investigate why

Remember: Power Query is strict about date formats. When in doubt, use the locale specific conversion method rather than the generic "Change Type" option.
