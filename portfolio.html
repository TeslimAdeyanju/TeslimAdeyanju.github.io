Flagship Projects

The work that best shows how I combine finance, data engineering and analytics.

NHS Financial Analytics

GitHub

An end to end Python pipeline that loads NHS England Trust Accounts Consolidation data for 206 trusts across three financial years into a MySQL star schema. Analytical views and key performance indicators feed a Power BI dashboard that shows which trusts are most exposed as the sector moved from surplus to deficit.

PythonMySQLETLPower BI

Superstore Sales & Profit Prediction

GitHub

A retail analytics project that examines sales, discounts and profitability by category, segment and region, then trains a logistic regression model to separate profitable orders from loss making ones. A Flask prediction service, an example client and a Dockerfile are included, and the write up is open about the limits of the model so far, including a risk of target leakage.

PythonScikit-learnFlaskDocker

NHS Waiting List Analytics

GitHub

Tests whether changes in NHS waiting lists come from treatment capacity or from the number of patients starting treatment pathways, using NHS England Referral to Treatment statistics. The waiting list rose from about 4.4 million before COVID-19 to about 7.5 million in 2024 to 2025, and waits over 52 weeks grew from under 2,000 to over 300,000. Python, MySQL, Databricks and Power BI are used end to end.

PythonMySQLDatabricksPower BI

Python, Finance & Automation

Python workflows for financial data, applied machine learning, model deployment and automated reporting.

Financial Data Pipeline (opens on GitHub)

GitHub

A modular data engineering project that gathers economic indicators and market prices from public sources into reproducible research datasets. Extraction uses yfinance and pandas datareader, and the repository holds the saved datasets and exploratory notebooks. Forecasting and a trading simulation are planned as later phases.

PythonAPIsPandasyfinance

GitHub

Seven numbered modules that turn finance and business questions into prediction tasks, from regression and classification to decision trees and ensembles, finishing with a deployed model. The final module serves a customer churn model through a Flask endpoint that returns a probability, with a Dockerfile and saved model included, and the course also covers model evaluation and random forests.

SQL & Databases

MySQL data models, analytical SQL queries and Python integration.

MySQL: Fundamentals to Advanced (opens on GitHub)

GitHub

Three modules from MySQL basics to stored programs on the ClassicModels sample database, run from Python so every query returns a clean pandas data frame. The basics module covers joins, grouping, subqueries and set operations, the functions module covers aggregate, string, date, window and pattern matching, and the advanced module covers procedures, loops, cursors, transactions and error handling.

MySQLPythonJupyter

UK Immigration: YouTube Sentiment (opens on GitHub)

GitHub

Collects public comments on two UK immigration videos through the YouTube Data API and stores them in MySQL, as the groundwork for sentiment analysis. It gathers up to 100 top level comments per video and keeps the comment text and metadata in a local MySQL database. Airflow, sentiment models and a Streamlit app are planned next.

PythonMySQLYouTube API

Machine Learning

Prediction, classification and explainability work on business data.

Product Price Prediction & Analytics (opens on GitHub)

GitHub

Investigates how product features drive price, using a first case study of 53,940 diamonds, with a Streamlit app that estimates a price from quality grades and measurements. It compares linear regression, decision tree and random forest models, and reports an R squared of 0.98 for the tuned random forest, although those results await a fully documented rerun.

PythonScikit-learnXGBoostStreamlit

Salary Prediction with SHAP (opens on GitHub)

GitHub

Explores how job title, experience, location and remote work relate to salary, comparing a PyTorch neural network with linear regression, random forest and XGBoost. The repository includes the cleaned and encoded datasets, and the models are compared on mean absolute error, root mean squared error and R squared. SHAP explanations are the stated next step.

PythonPyTorchXGBoostSHAP

Lead Conversion Model (opens on GitHub)

GitHub

Frames lead conversion as a classification problem on the Kaggle leads dataset, with a plan for an interpretable logistic regression baseline and lead scoring bands. The repository holds an exploratory notebook in Jupyter and Marimo and a detailed scope of work document. Model evaluation and calibration are still to be built, so this is early stage work.

PythonScikit-learnMarimo

Retail Marketing Prediction (opens on GitHub)

GitHub

Profiles mobile shop customers and trains an XGBoost classifier to tell repeat phone buyers from first time customers, using demographics, price and Facebook engagement. The project saves the trained model and reports accuracy and area under the curve. A Streamlit interface is included as a demonstration and is not yet linked to the model.

PythonXGBoostStreamlit
